# ذاكرة مشروع QINAA

هذا المجلد هو نقطة الدخول السريعة لأي مطوّر أو مساعد برمجي يعمل على المشروع. حدّثه مع كل قرار مهم، ولا تضع فيه أسراراً.

## ترتيب القراءة

1. [`product.md`](product.md): الهوية والجمهور وتجربة الاستخدام.
2. [`game-rules.md`](game-rules.md): قواعد اللعب المعتمدة.
3. [`architecture.md`](architecture.md): البنية التقنية وخريطة الملفات.
4. [`current-status.md`](current-status.md): ما يعمل فعلاً وما يزال محلياً أو ناقصاً.
5. [`operations.md`](operations.md): الإعداد والنشر والأسرار.
6. [`decisions.md`](decisions.md): القرارات التي لا ينبغي تغييرها دون موافقة.

## حقائق ثابتة

- الاسم: **قِناع — QINAA**.
- الشعار: **الحقيقة خلف القناع.**
- الدومين: `qinaaapp.com`.
- المنتج: لعبة استنتاج اجتماعي عربية، تبدأ من متصفح الهاتف.
- التقنية الحالية: HTML/CSS/JavaScript، Cloudflare Workers، D1، Durable Objects، LiveKit.
- الواجهة: عربية فصحى، RTL، IBM Plex Sans Arabic، داكنة/بنفسجية/صفراء.

عند التعارض، الكود هو وصف التنفيذ الحالي، و`game-rules.md` هو وصف السلوك المطلوب. يجب تسجيل الفجوة في `current-status.md`.
